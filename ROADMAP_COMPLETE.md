# 🗺 GameBot: Итоговый Roadmap (v2.0 Complete)

Проект успешно переведен из стадии прототипа в полноценное модульное приложение, оптимизированное для работы на Raspberry Pi.

## ✅ Реализованные возможности (Done)

### 1. Системный мониторинг (RPi Health)
- [x] Автоматические уведомления о перегреве (Warning 65°C / Crit 75°C).
- [x] Детекция проблем с питанием (Undervoltage / Throttling).
- [x] Команда `/status` (кнопка в меню) с детальной статистикой CPU, RAM, Диска и Uptime.

### 2. Игровые новости (AI Powered)
- [x] **Параллельный парсинг**: Одновременный опрос всех RSS-источников через `httpx`.
- [x] **Gemini 2.5 Flash**: Интеллектуальный пересказ новостей на русский язык.
- [x] **Умный парсинг**: Извлечение JSON через Regex, исправление кавычек и 3 попытки при сбое нейросети.
- [x] **Модерация**: Кнопки Одобрить/Отклонить для админа.
- [x] **Фильтры**:
    - Глобальный список ключевых слов (Gaming Keywords).
    - Команды для блокировки новостей по тегам (`/blocktag`).

### 3. Мониторинг цен (Kaspi & OLX)
- [x] **Поддержка ссылок**: Конкретные товары, категории или результаты поиска.
- [x] **Асинхронность**: Парсинг не блокирует работу бота.
- [x] **Дайджесты**: Группировка находок в категории каждые 30 минут (защита от спама).
- [x] **История цен**: Сохранение динамики для каждого товара (кнопка в управлении).
- [x] **Управление**: Удаление и редактирование целевых цен через Telegram.

### 4. Управление и Инфраструктура
- [x] **Динамические источники**: Добавление/удаление RSS и ключевых слов через команды (`/addrss`, `/addkw`).
- [x] **Стабильность БД**: SQLite в режиме WAL + `aiosqlite` + `asyncio.Lock` (0 ошибок блокировки).
- [x] **Безопасность**: Декоратор `@admin_only` на всех критических функциях.
- [x] **Обслуживание**: Ротация логов (макс 5МБ, 3 архива).
- [x] **Чистота**: Файл `requirements.txt` и перенос старых скриптов в `archive/`.
