# 🎮 GameBot v2: Gaming News & Price Monitor

Многофункциональный Telegram-бот, оптимизированный для работы на **Raspberry Pi (DietPi/Debian)**. Бот сочетает агрегатор игровых новостей с ИИ-пересказом (Gemini) и систему мониторинга цен (Kaspi, OLX).

## 🚀 Что нового в v2
*   **Модульная архитектура**: Код разбит на логические части (`database`, `jobs`, `ai_utils`, `config`).
*   **Полная асинхронность**: Переход на `aiosqlite` и `httpx`. Бот не блокируется при тяжелых запросах.
*   **Стабильность БД**: Использование режима **WAL** и глобальных блокировок (`asyncio.Lock`) предотвращает ошибки "database is locked".
*   **Динамические настройки**: Управление списком RSS-лент и ключевых слов прямо через Telegram.
*   **Параллельный парсинг**: Проверка всех источников новостей происходит одновременно.

## 🛠 Возможности

### 1. Новости с ИИ-пересказом
*   **Сбор**: Мониторинг игровых ресурсов через RSS.
*   **Gemini AI**: Автоматический суммаризатор на русский язык. Умный парсинг JSON с защитой от ошибок нейросети.
*   **Модерация**: Система Approve/Reject для админа.
*   **Фильтры**: Блокировка новостей по тегам (`/blocktag`) и ключевым словам (`/addkw`).

### 2. Мониторинг цен (Kaspi & OLX)
*   **Гибкость**: Отслеживание как конкретных товаров, так и целых категорий/результатов поиска.
*   **Дайджесты**: Группировка уведомлений, чтобы не спамить в чат.
*   **История**: Сохранение динамики цен для каждого товара.

### 3. Здоровье Raspberry Pi
*   Автоматические алёрты при перегреве (65°C+) или проблемах с питанием (**Undervoltage**).
*   Статистика нагрузки (CPU, RAM, Disk, Uptime) через кнопку `📊 Статус`.

## 📋 Команды управления (Админ)

### Настройка контента
*   `/addrss <url>` / `/delrss <url>` — управление источниками новостей.
*   `/addkw <слово>` / `/delkw <слово>` — управление фильтром интересов.
*   `/blocktag <тег>` — скрыть новости с определенным тегом от ИИ.
*   `/listrss`, `/listkw`, `/blockedtags` — просмотр списков.

### Мониторинг цен
*   `/watch_kaspi <url> <цена>` — быстрая постановка на мониторинг.
*   `/watch_olx <url> <цена>` — аналогично для OLX.
*   `/watches` — список всех подписок.
*   `/unwatch <id>` — удалить мониторинг.

## ⚙️ Установка

1. **Клонируйте репозиторий** и создайте файл `.env`:
   ```env
   BOT_TOKEN=ваш_токен
   GEMINI_API_KEY=ваш_ключ
   ADMIN_ID=ваш_id
   CHANNEL_ID=@ваш_канал
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск**:
   ```bash
   python3 bot.py
   ```
